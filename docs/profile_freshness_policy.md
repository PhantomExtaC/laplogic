# Profile freshness policy

Directory biographies, career totals, active flags, roster memberships and track
records retain unknown coverage until their own producer supplies evidence. Live
standings dates never establish freshness for those fields. A successful copy or
export does not establish coverage. The updater run report lists each resource as
sample, dated (known dataThrough), or unknown; dated does not mean current.

Standings and results-derived resources bind the same season, cutoff and source
snapshot. Calendar observation time describes schedule retrieval; result coverage
describes recorded outcomes. No elapsed-day threshold determines correctness:
off-weeks can legitimately preserve the same round. Compare source round coverage
before calling a resource current. Optional unavailable metrics stay null. Critical
fetch/validation failures preserve the candidate pointer and previous release.

Publication must keep these distinctions visible and must not relabel cached
directory team membership as a live roster. Directory refresh and historical
career-total verification remain outstanding before full U3 completion.
